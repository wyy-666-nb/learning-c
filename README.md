## 两类文件的区别

- **`syntax-drill/`** —— 学到一个新语法，就复制 `00-模板.c`，重命名成 `序号-语法点.c` 来写。
  目的是**加深印象**，每个语法点单独一个文件，以后复习时好找。

- **`01-basics/` 等目录** —— 学完一章后，**关掉视频、自己独立写**的完整小程序。
  这类文件才是真正属于我的作品。
