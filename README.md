## 踩过的坑

记录下来，避免以后重复踩。**前 4 个是环境类的，后面是语法和指针类的。**

### 1. 中文注释导致编译报错（最坑的一个）

**症状**：代码明明没写错，却报"未声明的标识符""语法错误"。

**原因**：源文件是 UTF-8 但没有 BOM，MSVC 会按 GBK 读取。中文注释的最后一个字节会把后面的换行符"吃掉"，导致下一行代码被并进注释里，大括号结构随之错乱。

**解决**：所有 `.c` 文件保存为 **UTF-8 带签名（BOM）**。

### 2. VS 项目的命名

- 项目名称**不要带 `.c` 后缀**——否则源文件会被命名成 `xxx.c.c`
- 项目名称和文件夹名**不要有空格**——否则生成中间目录时名字会被截断（`037-character function` 就是反例）

### 3. Windows 11 智能应用控制

它会拦截所有自己编译的、没有数字签名的 `.exe`。学编程必须关掉它，否则程序编译成功却运行不了。

### 4. 批处理文件（`.cmd` / `.bat`）的编码

- 编码要用 **GBK**（或纯英文内容）
- 换行必须是 **CRLF**
- 文件名尽量用 **ASCII**

### 5. 数组和字符串

| 坑 | 正确做法 |
| --- | --- |
| `int arr[10] = 0;` | `int arr[10] = {0};` |
| 数组名是常量地址，`arr2 = arr1` | 用 `strcpy` 或自己逐元素拷贝 |
| 二维数组做参数写成 `[ROW][COL]` | 第二维必须和实参一致，写 `[ROWS][COLS]` |
| 数组传参后 `sizeof(arr)/sizeof(arr[0])` | **失效**（退化成指针），长度必须单独传 |
| `'\0'` 写成 `'0'` | 前者值 0（结束符），后者值 48（数字零） |

### 6. 头文件与声明

- 头文件里的声明必须和 `.c` 里的定义**一字不差**（`char arr` ≠ `char arr[ROWS][COLS]`）
- 缺 `#include`：用 `strcmp` 要 `string.h`，用 `assert` 要 `assert.h`，用 `offsetof` 要 `stddef.h`

### 7. `printf` 格式符

- `%d` 只能配 `int`；**打印结构体必须逐成员**，没有格式符能打印整个结构体
- `%zu` 配 `size_t`，别写成 `"zu"`（漏了 `%` 就变成打印字面量）
- `%.20f` 能看清浮点数的误差

### 8. 符号和运算符

| 坑 | 说明 |
| --- | --- |
| 取位段成员地址 `&s._b` | 位段成员没有独立地址 → **C2104** |
| `n % 2 == 1` 判断奇数 | 对负数失效，应写 `n % 2 != 0` |
| `n & 1 == 0` | `&` 优先级低于 `==`，必须写 `(n & 1) == 0` |
| 比较函数写 `return a - b` | 大数相减会溢出，应写 `(a > b) - (a < b)` |
| `memcmp` / `strcmp` 返回值 | **只保证正负**，不保证具体数值（MSVC 的 `memcmp` 返回 ±1） |
| `unsigned` 循环条件 `i >= 0` | 恒为真 → 死循环 |

- **IDE**：Visual Studio 2026 Community（MSVC 14.51）

## 常用命令

```powershell
# 提交并推送
git add .
git commit -m "feat: 添加 xxx 练习"
git push

# 看状态（出现 [ahead] 说明还有提交没推上去）
git status -sb

# 看提交历史
git log --oneline

# 检查文件有没有 BOM
$b = Get-Content -Encoding Byte -TotalCount 3 .\xxx.c
($b -join ',') -eq '239,187,191'    # True 就是有 BOM

# 补救：给没有 BOM 的 .c 文件补上
Get-ChildItem -Recurse -File -Include *.c,*.h | ForEach-Object {
    $t = Get-Content -Raw -Encoding UTF8 $_.FullName
    Set-Content -Path $_.FullName -Value $t -Encoding UTF8 -NoNewline
}
```
